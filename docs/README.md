> 急的事不做，急了容易出错；不急的事不做，都不急做什么做?

### Make Decisions for Yourself

> 唯一比做出糟糕决定更糟糕的事情，就是不做任何决定。
>
> 你必须不断做出决定来强推着自己前进。
>
> 你才是你自己生活的唯一权威，你对自己负责，你的命运不要轻而易举地被其他人所决定。
>
> 面对重大决策，最可怕的是无感和逃避，把决定权交给别人，如果出了事，自己可以心安理得地怪罪环境或对方。
>
> 永远不要在接收到信息的当天做决定。凡是要求你“立刻、马上”决定的重大事项，往往不是在为你的人生考虑，而是在为你的人生“收割”。
>
> 建立你的“决策缓冲带”；识别“伪急迫感”；使用“10/10/10 决策法”；学会“有预留的等待”。
