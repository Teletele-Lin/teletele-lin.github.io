内容管理

在 Pages CMS 中编辑文章、上传图片，为专题和文章选择封面。保存后的内容会提交到博客的 GitHub 仓库。

打开 Pages CMS

第一次使用

  1. 先将本次配置提交并推送到博客仓库的 main 分支。
  2. 打开 Pages CMS，使用 GitHub 登录；安装其 GitHub App，选择授权 Teletele-Lin/teletele-lin.github.io 仓库。
  3. 进入该仓库的 main 分支，确认出现“文章正文”“卡片与封面”和“图片库”。
媒体

上传与复用图片

进入“图片库”，上传图片后可在正文编辑器中插入，也可以在“卡片与封面”里选作封面。

支持 JPG、PNG、WebP、GIF、AVIF。已迁移的文章图片可在库内复用，正文也支持外部图片链接。

写作

编辑文章正文

在“文章正文”中找到文章，可使用可视化编辑或 Source 源码模式。有代码块、表格或自定义 HTML 时，优先使用 Source 模式。

新建文章后，还需要在“卡片与封面”中添加对应卡片，才能显示在专题页。

展示

管理卡片与封面

修改标题、摘要、关键词和显示顺序；在“封面图片”中上传或选择图片。留空会继续使用文字封面。

专题与子目录使用稳定的目录标识关联，例如 postgres、query、tools、ai。

保存与发布

Pages CMS 直接修改 GitHub 仓库，保存后等待 GitHub Pages 发布完成，再刷新博客查看。现有文章的路径应保持稳定；如需重命名，记得同步修改卡片路径和推荐阅读。

图片库中的文件也可能被正文引用，删除前请检查引用情况。
